# ЛР №3 «Языки программирования» — OpenCL (определитель матрицы + брутфорс SHA-256)

Готовый проект под VS Code: CPU-версии (чистый C, запускаются без доп. зависимостей)
и GPU-версии (C + OpenCL). Отчёт в `report/` уже готов, но графики в нём построены
по модели (см. раздел 7 отчёта) — если прогоните GPU-версии на своей видеокарте,
стоит заменить цифры в таблицах/графиках на реальные (как это сделать — ниже).

## Структура проекта

```
проект/
├── cpu/                    CPU-версии (компилируются ВЕЗДЕ, без OpenCL)
│   ├── sha256.h
│   ├── det_cpu.c            определитель матрицы методом Гаусса
│   └── bruteforce_cpu.c     перебор пароля по SHA-256
│
├── gpu/                     GPU-версии (нужен OpenCL SDK, см. ниже)
│   ├── sha256.h             (нужен только host-программам для проверки/генерации тестового хэша)
│   ├── det_kernel.cl        OpenCL-ядро для метода Гаусса
│   ├── det_host.c           host-программа для det_kernel.cl
│   ├── bf_kernel.cl         OpenCL-ядро для брутфорса SHA-256
│   └── bf_host.c            host-программа для bf_kernel.cl
│
├── scripts/                 скрипты сборки из командной строки
│   ├── build_cpu.bat / .sh
│   └── build_gpu.bat / .sh
│
├── data/                     CSV с результатами замеров (CPU — реальные, GPU — расчётные)
├── report/                   готовый docx-отчёт + графики/схемы (PNG)
├── .vscode/                  задачи сборки, IntelliSense, отладка — для VS Code
└── README.md                 этот файл
```

## Шаг 1. Запустить CPU-версии (можно прямо сейчас, без установки чего-либо кроме компилятора)

### Windows
1. Поставьте компилятор, если его нет: **MSYS2** → https://www.msys2.org/, после установки
   в терминале MSYS2 выполните `pacman -S mingw-w64-ucrt-x86_64-gcc` и добавьте
   `C:\msys64\ucrt64\bin` в `PATH` (или используйте любой другой MinGW-w64/TDM-GCC).
2. Откройте папку проекта в VS Code (`File → Open Folder…`).
3. Поставьте расширение **C/C++** (Microsoft) — IntelliSense и отладка уже настроены в `.vscode/`.
4. Соберите: `Terminal → Run Task… → Build: CPU (det_cpu)` и `Build: CPU (bruteforce_cpu)`,
   либо просто в терминале:
   ```
   scripts\build_cpu.bat
   ```
5. Запустите:
   ```
   cpu\det_cpu.exe
   cpu\bruteforce_cpu.exe
   ```

Обе программы сами печатают таблицу результатов (размер входных данных → время в мс) —
это CPU-строки таблиц 1 и 2 в отчёте.

## Шаг 2. Запустить GPU-версии (нужен OpenCL SDK + драйвер видеокарты с поддержкой OpenCL)

### 2.1 Проверьте, что у вас вообще есть OpenCL
- **Windows:** драйвер видеокарты (NVIDIA/AMD/Intel) уже содержит OpenCL runtime —
  обычно отдельно ставить ничего не нужно, нужны только **заголовки и .lib для компиляции**.
- **Linux:** `sudo apt install clinfo && clinfo` — должно показать хотя бы одну платформу/устройство.
  Если пусто — поставьте ICD вашей видеокарты:
  `nvidia-opencl-icd` (NVIDIA) / `mesa-opencl-icd` (AMD, через Mesa) / `intel-opencl-icd` (Intel).

### 2.2 Получите заголовки/библиотеку OpenCL для компиляции

У вас в похожем старом проекте уже была папка **OLSDK** (видно на скриншоте,
`Игнатова_OpenCL\OLSDK`) — если она сохранилась, этого достаточно, в ней должны быть
`OLSDK\include\CL\cl.h` и `OLSDK\lib\x86_64\OpenCL.lib`. Просто скопируйте папку `OLSDK`
рядом с этим проектом (на один уровень с `cpu/`, `gpu/`).

Если такой папки нет — варианты:
- **Khronos OpenCL-SDK** (кроссплатформенный, самый простой): https://github.com/KhronosGroup/OpenCL-SDK/releases —
  скачайте архив для Windows, распакуйте, переименуйте папку в `OLSDK` (или поменяйте путь
  в `scripts/build_gpu.bat`).
- **vcpkg**: `vcpkg install opencl` — тогда вместо `-I`/`-L` используйте путь к
  `vcpkg/installed/x64-windows/{include,lib}`.
- Заголовки/либа также идут вместе с **CUDA Toolkit** (NVIDIA) в подпапке `include/CL` —
  если у вас уже стоит CUDA, можно использовать её.
- **Linux:** `sudo apt install ocl-icd-opencl-dev` — поставит и заголовки, и `libOpenCL.so`,
  путь указывать не нужно.

### 2.3 Сборка

**Windows** (из корня проекта, в обычном cmd/PowerShell или терминале VS Code):
"C:\_tr\y3nogit\proj\OLSDK"
```
set OCL_SDK=путь\до\OLSDK
set OCL_SDK=C:\_tr\y3nogit\proj\OLSDK
scripts\build_gpu.bat
```
(если переменную `OCL_SDK` не задать, скрипт по умолчанию ищет папку `OLSDK` рядом с проектом).

Либо через VS Code: `Terminal → Run Task… → Build: GPU (det_host, OpenCL) - Windows/OLSDK`
(и аналогично для `bf_host`) — тоже требует заданной переменной окружения `OCL_SDK`.

**Linux:**
```bash
./scripts/build_gpu.sh
```

### 2.4 Запуск

**Важно:** `.cl`-файлы (`det_kernel.cl`, `bf_kernel.cl`) читаются host-программой по
относительному пути, поэтому запускать исполняемые файлы нужно **из папки `gpu/`**:

```
cd gpu
det_host.exe        (или ./det_host на Linux)
bf_host.exe          (или ./bf_host на Linux)
```

- `det_host` сгенерирует матрицу 800×800, вычислит определитель на GPU и выведет его.
- `bf_host` подберёт захардкоженный тестовый пароль `"zzzzz"` (5 символов) по SHA-256 на GPU
  и выведет найденный индекс — сверьте его с тем, что выдаёт `cpu/bruteforce_cpu` для той же длины
  (это и есть проверка корректности из раздела 6 отчёта).

Если нужно подобрать **свой** пароль/хэш, а не тестовый — поменяйте строку
`const char* target = "zzzzz";` в `bf_host.c` (или допишите чтение хэша из консоли,
как было в примере от предыдущих студентов).

## Шаг 3. Замерить время и обновить отчёт реальными GPU-цифрами (по желанию, но рекомендуется)

1. В `det_host.c` / `bf_host.c` добавьте замер времени вокруг
   `clEnqueueNDRangeKernel` + `clFinish` (например, через `QueryPerformanceCounter` на
   Windows или `clock_gettime(CLOCK_MONOTONIC, …)` на Linux) и прогоните для тех же
   размеров, что в отчёте (n = 100…1600 для матрицы, L = 1…6 для брутфорса).
2. Замените значения в `data/det_combined.csv` и `data/bf_combined.csv` на свои.
3. Перестройте графики и впишите новые числа и выводы в `report/ЛР3_ЯП_OpenCL.docx`
   (таблицы 1–2, рисунки 3–5, текст раздела 7) — это сделает отчёт полностью «вашим»,
   с реальными измерениями на вашем железе, а не расчётной моделью.

## Частые проблемы

| Проблема | Решение |
|---|---|
| `CL/cl.h: No such file or directory` | Не задан `-I` к папке с заголовками OpenCL — проверьте `OCL_SDK` / путь в скрипте |
| `cannot find -lOpenCL` / `undefined reference to clGetPlatformIDs` | Не задан `-L`/`-l OpenCL`, либо нет `OpenCL.lib`/`libOpenCL.so` по указанному пути |
| `Error: creating context` при запуске | Нет GPU-устройства OpenCL — проверьте `clinfo` / диспетчер устройств, обновите драйвер видеокарты |
| Программа падает / не находит `kernel.cl` | Запускайте `.exe` строго из папки `gpu/`, а не из корня проекта |
| На ноутбуке только встроенная графика без OpenCL | В `det_host.c`/`bf_host.c` замените `CL_DEVICE_TYPE_GPU` на `CL_DEVICE_TYPE_CPU` — OpenCL умеет выполняться и на CPU как на обычном устройстве (это тоже валидно для проверки корректности, просто не даст ускорения) |
